# homebrew-sessync

Homebrew tap for [sessync](https://github.com/echobyte26/sessync) — cross-device
sync for Claude Code agent sessions.

## Install

```bash
brew tap echobyte26/sessync
brew install sessync
```

`brew upgrade sessync` to pull a new release once one lands.

## Uninstall

```bash
brew uninstall sessync
brew untap echobyte26/sessync
```

If you also want to wipe your config + Keychain entry, run `sessync uninstall`
**before** `brew uninstall`.
